# Agent instructions

If you are an AI agent working in this repo:

1. Follow the code rules in [CLAUDE.md](CLAUDE.md). They apply to every agent, not only Claude.
2. Follow the issue process in [CONTRIBUTING.md](CONTRIBUTING.md): claim the issue, work on a branch, run `pnpm check`, then open a PR that links the issue. **Never commit to `main`, never merge, never deploy.**
